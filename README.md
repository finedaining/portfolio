대구 지하철 노선도 (2025.07 / 4인 팀 프로젝트)

대구 지하철 1, 2, 3호선 노선도에서 출발역과 도착역을 고르면 가장 빠른 경로와 도착 시간을 알려주는 데스크톱 앱입니다. Python과 Tkinter로 만들었습니다.

맡은 역할 (프론트엔드)

- Tkinter로 대구 지하철 1, 2, 3호선 노선도를 직접 찍어서 만들었습니다
- 역마다 위치를 좌표로 잡고 노선을 이어서 앱의 메인 화면을 만들었고 팀원과 함께 다듬어 완성했습니다
- 발표 PPT를 디자인하고 팀원과 같이 발표했습니다
- Tkinter와 Tkinter Designer는 이번 프로젝트를 하면서 처음 배워서 바로 써봤습니다

성과

- 9일 동안 기획부터 디자인과 개발까지 끝내고 실제로 돌아가는 앱을 완성했습니다
- 제가 만든 노선도가 앱의 메인 화면으로 쓰였습니다
- 사용자는 노선도에서 역을 눌러 출발지와 도착지를 정하고 가장 빠른 경로와 도착 시간을 확인할 수 있습니다
- 환승역과 지나가는 역 표시와 역 검색과 즐겨찾기와 최근 검색 기능도 함께 완성했습니다

배운 점

- Tkinter는 화면 요소를 좌표로 하나하나 배치해야 해서 복잡한 화면을 만들기가 생각보다 어려웠습니다
- 회의를 더 자주 했으면 역할을 더 분명하게 나눌 수 있었을 것 같습니다

두드림 (2025.09 - 2025.10 / 4인 팀 프로젝트)

기계부품 제조 브랜드 두드림의 재고와 판매와 재무 데이터를 한곳에서 관리하는 사이트입니다. React와 Spring Boot와 MariaDB로 만들었고 Python OCR과 Brity RPA를 연동했습니다.

맡은 역할 (프론트엔드 + 디자인)

- 두드림 로고를 직접 디자인했습니다
- 브랜드 컬러와 폰트를 정하고 피그마로 와이어프레임과 화면 레이아웃을 설계했습니다
- CSS로 전체 페이지의 스타일과 레이아웃을 정리했습니다
- 다양한 화면 크기에 맞게 반응형 UI를 구현했습니다

성과

- 판매 사이트와 관리자 대시보드와 OCR과 RPA까지 이어지는 재고·판매 관리 시스템을 팀원들과 완성했습니다
- 발주서 사진을 올리면 OCR로 글자를 읽어 제품 정보가 자동으로 입력되고 RPA로 매출 분석 보고서를 만들어 메일로 보내는 흐름을 만들었습니다
- 기업 사용자와 관리자 화면을 나눠 로그인과 상품 주문부터 매출 대시보드와 제품 관리와 고객 관리까지 구현했습니다
- 실제 재무 흐름을 반영한 목업 데이터를 써서 대시보드가 현실적인 수치를 보여주도록 했습니다

배운 점

- 재무제표와 손익계산서를 DB로 관리하는 시스템까지 발전시키지 못한 점이 아쉬웠습니다
- 회사와 상품 정보를 충분히 담지 못해서 실제 서비스처럼 만들려면 데이터 설계를 처음부터 더 꼼꼼히 해야 한다는 걸 배웠습니다

빈티지하우스 (2025.05 - 2025.06 / 4인 팀 프로젝트)

프리미엄 빈티지 가구 브랜드의 쇼핑몰을 React와 Node.js와 MariaDB로 만든 웹 프로젝트입니다.

맡은 역할 (프론트엔드)

- 메인 페이지와 이벤트 페이지를 맡아 디자인하고 React로 구현했습니다
- 메인 이미지 자동 슬라이드와 마우스를 올리면 사진이 바뀌는 기능을 만들었습니다
- 가로 스크롤과 화살표로 넘기는 캐로셀과 자동으로 흐르는 텍스트 배너를 구현했습니다
- 이벤트 팝업 창을 디자인하고 이벤트 페이지로 바로 이동하게 연결했습니다
- 할인 쿠폰과 출석 체크 캘린더가 있는 이벤트 페이지 화면을 만들었습니다

성과

- 기획부터 디자인과 개발과 DB 연동까지 실제 쇼핑몰처럼 돌아가는 사이트를 팀원들과 완성했습니다
- 매일 작업이 끝나면 진행 상황을 공유하면서 일정을 조정했고 덕분에 협업이 원활했습니다
- React와 GitHub와 데이터베이스를 처음 써보면서 각각의 역할과 흐름을 직접 익혔습니다

배운 점

- 처음 디자인할 때 넣고 싶던 기능이 많았는데 시간이 부족해 여러 개를 빼야 했습니다
- 공통 디자인을 먼저 정하지 않고 각자 작업해서 나중에 수정할 때 어려움이 있었습니다
- GitHub를 처음 써서 충돌을 해결하는 데 시간이 많이 들었고 다음엔 브랜치 관리부터 제대로 익히고 싶습니다

수익성 개선 자동 분석 시스템 (2025.08 / 3인 팀 프로젝트)

기업 재무 데이터를 자동으로 모으고 분석해서 수익성 지표와 개선안을 차트로 만들고 메일로 보내주는 RPA 시스템입니다. Brity RPA와 Python과 Excel을 사용했습니다.

맡은 역할 (데이터 관리)

- DART API로 받아온 재무 데이터를 엑셀 표로 정리하고 분석에 맞게 가공했습니다
- 매출액과 영업이익률과 영업비용률을 기업별 분기별로 비교할 수 있게 피벗 테이블과 차트로 정리했습니다
- LG전자 2025년 데이터를 넣고 개선 전후를 비교하는 표를 만들었습니다

성과

- 데이터 수집부터 가공과 시각화와 메일 발송까지 한 번에 돌아가는 자동화 흐름을 완성했습니다
- LG전자와 삼성전자의 2020년부터 2024년까지 분기별 수익성을 한눈에 비교할 수 있게 만들었습니다
- 개선안을 적용하면 LG전자 영업비용률이 94.8%에서 88.6%로 줄고 절감률이 6.63%라는 결과를 냈습니다

배운 점

- API에서 받을 수 있는 데이터가 한정적이라 분석을 더 깊게 하지 못한 게 아쉬웠습니다
- 피벗 테이블은 클릭으로만 처리해야 하는 부분이 많아서 RPA 반복 기능을 충분히 쓰기 어려웠습니다
